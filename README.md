# Lights Out Game

---

## Descrição

> Este jogo foi desenvolvido como parte da disciplina Programação II e Redes Aplicadas com o objetivo de conectar ao menos dois jogadores localmente para resolução de puzzle em client. O jogador controla um personagem que interage com plataformas para realizar o puzzle.

---

## Estrutura do Projeto

| Arquivo              | Descrição                                                  |
|----------------------|------------------------------------------------------------|
| `BP_Character`       | Clone do Character base do TopDown da Unreal Engine 5.     |
| `BP_Controller`      | Clone do Character base do TopDown da Unreal Engine 5.     |
| `BP_GameMode`        | Clone do Character base do TopDown da Unreal Engine 5.     |
| `BP_Platform`        | Plataforma com TriggerBox para alternar estados.           |
| `WB_MainMenu`        | Gerencia o Menu junto as funções de Host e Join.           |
